A 4 KB Python chess engine with alpha-beta search, quiescence search, a transposition table, null-move pruning, killer moves, and late move reductions. It plays the house gauntlet through the make.fun env, searching up to 100,000 nodes per move on a fixed budget with no clock and no randomness, so every trial replays identically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
